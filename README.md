# AimLabs

Lightweight, modern browser-based 3D aim trainer built with Vanilla JavaScript, Three.js, and WebAudio.

## Quick Start

Serve locally using any local HTTP server (required for ES module loading) and open in your browser:

```bash
# From the project root
python3 -m http.server 8001
# Open http://localhost:8001 in your browser
```
